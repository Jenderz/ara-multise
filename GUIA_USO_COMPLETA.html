2. Guía de Uso Rápido

Gestión de Pedidos (Delivery Global)

  1. Un cliente realiza un pedido en la tienda online. Entra como pending a la Sede Principal.
  2. En el panel Admin, los pedidos globales aparecen resaltados con un borde naranja.
  3. El operador de cualquier sede (ej. Sede Norte) visualiza el pedido.
  4. Al hacer clic en "Completar / Entregar", el sistema transfiere el pedido a la Sede Norte y descuenta el stock del inventario de dicha sede.

Uso del Punto de Venta (POS)

  1. El vendedor ingresa al módulo POS desde su sucursal.
  2. Al buscar un producto, el sistema muestra el Stock Local. Si no hay, muestra el Stock Global de otras sedes.
  3. Se agrega al carrito y se cobra. El sistema registra la venta automáticamente bajo el canal "POS" y descuenta el stock localmente.

Mover Stock entre Sedes

  1. En el módulo de Inventario, seleccionar la opción de Transferir.
  2. Seleccionar el producto (y su variante, si aplica).
  3. Indicar Sede Origen, Sede Destino y Cantidad.
  4. El sistema registrará el movimiento en product_movements con el tipo transfer.

3. Arquitectura y Seguridad

  • Frontend: React 18.3, TypeScript 5.8, Vite, TailwindCSS.
  • Backend: PHP 8.0+, Base de datos MySQL con Procedimientos Almacenados.
  • Seguridad DB: Triggers (trg_inventory_check_negative) previenen inconsistencias.
  • Roles: Admin (Acceso total), Vendedor (Solo POS y su sede), Master.
  • Despliegue: Frontend preparado para Vercel/Netlify. Backend en VPS/cPanel clásico.
